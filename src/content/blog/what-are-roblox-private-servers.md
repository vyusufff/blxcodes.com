A **private server** (sometimes called VIP server) is a locked instance of an experience. You control who gets in — friends, clanmates, or just you.

## Why games offer them

- Practice without randoms griefing.
- Record videos / TikToks with a clean lobby.
- Clan events and tryouts.
- Quiet farming in simulators (still follow each game’s rules).

Developers can charge a one-time or subscription Robux fee. Pricing is set per experience.

## How to buy / start one

1. Open the experience’s Roblox page.
2. Find **Servers** → **Private Servers** / **VIP**.
3. Create or buy according to the game’s options.
4. Set it to friends-only or generate an invite link if the game supports it.

Not every game has private servers. If the button is missing, the developer didn’t enable them.

## Who can join

Depends on the owner’s settings:

- Friends only
- People with the link
- Specific users allowed by the host

Public servers remain available separately — buying VIP doesn’t remove public lobbies.

## Tips

- Don’t share VIP links in huge Discords if you want them to stay private.
- Cancel recurring VIP subscriptions you no longer use.
- Private servers are not “admin abuse” by default — you only get powers the developer coded for VIP owners.

If you just want to play casually, public servers are enough. Private servers shine for practice groups and content creation.
