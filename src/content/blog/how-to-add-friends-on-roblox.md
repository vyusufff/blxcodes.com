Friends let you join servers together, see presence, and chat (depending on privacy settings).

## Send a friend request

1. Open the player’s **profile** (search their username or click them in-game).
2. Tap **Add Friend** / **Friend**.
3. Wait for them to accept.

From an experience: open the player list → select the user → **Add Friend** if available.

## Accept a request

1. Open the **Friends** / **Connections** page or the notification bell.
2. Open **Requests**.
3. Accept or decline.

## Can’t add someone?

- Their privacy is set to **no friend requests** / friends-of-friends only.
- You’re blocked (or you blocked them).
- Account age / chat restrictions on one side.
- You already sent a pending request — wait or cancel it.

## Privacy tips for younger players

Parents can limit who can message or friend a child account. Encourage kids to only accept people they know offline.

After you’re friends, use **Join** / server invites when the game supports it — much easier than sharing obscure VIP links in public chat.
