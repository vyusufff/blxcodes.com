Roblox is cross-platform: start on a phone, continue on a PC with the same account. Performance and controls differ.

## Windows PC

1. Create or sign in at [roblox.com](https://www.roblox.com/).
2. Click play on any experience — Windows installs / opens the Roblox player.
3. Or install from the Microsoft Store if you prefer Store updates.
4. Use a mouse + keyboard for FPS and tycoon UIs; many games also support controllers.

## Mac

Use the official Roblox site download / player flow. Keep macOS updated; older OS versions sometimes lose support.

## iPhone / iPad

1. Install **Roblox** from the App Store.
2. Sign in with the same account.
3. Allow tracking / notifications only if you want them — not required to play.
4. Use a stable Wi‑Fi connection for large game downloads.

## Android

1. Install from the **Google Play** store (avoid APK sites).
2. Sign in and play.
3. If games fail to join, clear app cache or reinstall.

## Consoles

Roblox support on PlayStation / Xbox / other living-room devices depends on Roblox’s current platform list and your region. Create the account with parent approval when required, and link according to the on-screen console instructions.

## Which platform should you use?

| Need | Better on |
| --- | --- |
| Building in Studio | PC / Mac |
| Playing in bed / commute | Phone |
| Couch multiplayer | Console (if available) |
| Trading / catalog browsing | Website on any device |

One account everywhere — just don’t share the password across siblings without 2FA and clear rules.
