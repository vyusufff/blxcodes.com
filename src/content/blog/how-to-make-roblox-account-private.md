A “private” Roblox account usually means tightening **privacy settings**, not deleting the profile. You stay able to play while strangers see less.

## Core settings to change

1. Sign in → gear → **Settings** → **Privacy**.
2. Set **Who can message me** to Friends or No one.
3. Set **Who can invite me to experiences** carefully (Friends is a solid default).
4. Limit **Who can follow me** / join you from your profile.
5. Review inventory & trade visibility if those toggles appear for your account type.

Exact labels differ on mobile vs web — if you don’t see an option, check the website settings page.

## Profile cleanup

- Clear personal info from the **About** section (school, Discord, phone).
- Disable public activity feeds if available.
- Remove strangers from friends / block harassers.

## For parents

Use **parental controls** / account PIN features Roblox provides for child accounts. Pair privacy with 2FA on the parent email.

Privacy reduces stalking and scam DMs. It does **not** replace common sense in public servers.
