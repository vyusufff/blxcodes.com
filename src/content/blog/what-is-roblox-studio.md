**Roblox Studio** is the free PC/Mac tool creators use to build experiences: maps, scripts, GUIs, and monetization. Playing Roblox ≠ using Studio — Studio is the editor.

## What you can make

- Obbies, simulators, roleplay maps, horror games, shops.
- Scripts in **Luau** (Roblox’s language).
- Game passes, developer products, and badges.
- Publish updates your live experience sees.

## Install Studio

1. On a computer, open roblox.com while logged in.
2. Create or edit an experience → Roblox prompts the **Studio** install.
3. Or download Studio from Roblox’s official create pages.
4. Sign in with the same account.

Phones can play games; serious building still happens on desktop.

## First session checklist

1. Open a **Baseplate** template.
2. Learn **Move / Scale / Rotate** tools.
3. Insert a part; change color and anchor it so it doesn’t fall.
4. Press **Play** to test.
5. Save to Roblox often.

## Learning path that doesn’t overwhelm

- Week 1: parts, spawn, simple kill brick.
- Week 2: checkpoints / stage system tutorials.
- Week 3: basic leaderstats (coins).
- Later: DataStores, UI, monetization.

Free models are tempting — many include viruses or stolen assets. Prefer official documentation and trusted tutorials. Publish only what you’re allowed to use.
